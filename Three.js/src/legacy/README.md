# Legacy Moon prototype

`MoonPrototype.js` and `MoonPrototype.css` are retained only as a migration reference for the existing Three.js camera, marker, map and interaction work.

They are not imported by `src/main.tsx`, are not shipped by the production application, and must not be reintroduced as a source of astronomical, terrain, power, communications or landing-safety results. Phase 3 will extract the useful interaction code into focused modules with coordinate-calibration tests.
