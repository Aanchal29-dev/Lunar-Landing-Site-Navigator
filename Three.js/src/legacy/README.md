# Legacy Moon prototype

`MoonPrototype.js` and `MoonPrototype.css` are retained only as a migration reference for the existing Three.js camera, marker, map and interaction work. The useful coordinate interaction has now been rebuilt as focused production modules.

They are not imported by `src/main.tsx`, are not shipped by the production application, and must not be reintroduced as a source of astronomical, terrain, power, communications or landing-safety results. Do not replace the production globe with this standalone prototype.
